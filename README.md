# 格物实验室 · Gewu Lab

> 中学生数理化学习辅助工具——拖动参数、观察变化、验证猜想。每一次动手验证，都是一次「格物」。

**在线体验**：https://tian-liang.github.io/gewu-lab/

## 简介

面向初一至初三学生的纯客户端 Web 应用，覆盖人教版初中三年数理化全部章节。三个核心模块对位学习的三个断层：

| 模块 | 解决的问题 | 内容 |
|------|-----------|------|
| **动态实验室** | 抽象概念看不见 | 16 个可交互动画：函数参数、勾股定理、热机四冲程、电磁感应、微观粒子… |
| **知识精讲** | 知识点碎片化 | 342 个知识点卡片：定义、直觉解释、公式、例题、易错点、知识关联 |
| **练习 + 错题本** | 盲目刷题反复错 | 2068 道题、按章节组卷、四类错因归类、1/3/7/15 天间隔复习 |

另有：全局知识点搜索、离线使用（Service Worker）、数据本地保存 + 导出备份、移动端适配、彩蛋页（点品牌名）。

## 技术特点

- **纯客户端架构**：无后端、无数据库、零登录——构建产物扔到任意静态托管即可运行
- **数据本地化**：练习记录 / 错题本 / 掌握度存 IndexedDB，可导出 JSON 备份迁移
- **离线可用**：Service Worker 缓存，首次访问后断网可继续学习
- **性能**：路由级代码拆分（38 个 chunk），首屏约 54KB gzip，内容按学科懒加载
- **移动端防护**：canvas 渲染 DPR 钳制 + 像素预算、动画离屏/切后台自动暂停

## 技术栈

React 18 · TypeScript · Vite · Zustand · IndexedDB（idb）· KaTeX

## 本地开发

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
```

```bash
npm test           # 单元测试（22 个）
npm run build      # 类型检查 + 生产构建
node scripts/qa-questions.mjs   # 题库质检（结构 + 答案一致性）
node scripts/coverage-check.mjs # 中考考点覆盖度对照
node scripts/e2e-check.mjs      # Playwright 端到端检查
```

## 部署

推送到 `main` 分支即自动构建部署到 GitHub Pages（见 `.github/workflows/deploy.yml`）。

```bash
git push
```

构建产物全相对路径，可部署到任意子路径或用户页根域名。

## 项目结构

```
src/
  data/
    content/        # 内容数据：知识点 + 题库（按学科/年级分文件）
    knowledge.ts    # 内容聚合 + 章节分组 + 年级排序
    questions.ts    # 题库聚合与查询
  demos/            # 16 个 canvas 交互演示 + 画布环境工具
  pages/            # 首页 / 知识地图 / 实验室 / 练习 / 错题本 / 我的 / 彩蛋
  db/               # IndexedDB 存储层 + 掌握度/复习调度纯函数
  components/       # 搜索、公式渲染、错误边界
scripts/            # 题库质检、覆盖度对照、E2E 检查
```
